## Установка и запуск

1. Установить Python 3.
2. Поместить исходные анкеты в файл `anketa.txt`.
3. Убедиться, что каждая строка содержит пять полей, разделённых точкой с запятой:
   - тип анкеты (`s` — студент, `t` — преподаватель);
   - ФИО;
   - электронная почта;
   - телефон;
   - группа или кафедра.
4. Запустить программу командой:

```bash
python main.py
```

Программа проверяет анкеты, выводит список принятых записей и статистику, а также сохраняет результаты в файлы `ok.txt` и `errors.txt`.

Если файл `anketa.txt` отсутствует, программа выводит соответствующее сообщение.
