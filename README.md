# Обработчик анкет

Программа проверяет анкеты студентов: ФИО, электронную почту, телефон и группу.
Корректные анкеты выводятся в таблицу, а результаты сохраняются в файлы.

## Запуск

Требуется Python 3.

В терминале из папки проекта выполни:

```bash
python main.py
## Результаты работы

Программа сохраняет принятые анкеты в `ok.txt`
а отклонённые строки и причины ошибок — в `errors.txt`.
