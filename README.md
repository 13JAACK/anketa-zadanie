# Обработчик анкет

Программа читает анкеты из файла `anketa.txt`, проверяет корректность данных,
выводит принятые анкеты и статистику, а также сохраняет результаты в файлы.

## Структура проекта

- `main.py` — основной запуск программы и обработка анкет.
- `validators.py` — проверка и нормализация ФИО, почты, телефона и группы.
- `report.py` — вывод таблицы и статистики.
- `storage.py` — чтение исходного файла и сохранение результатов.
- `anketa.txt` — исходные данные.

## Запуск

1. Установить Python 3.
2. Поместить исходные анкеты в `anketa.txt`.
3. Запустить:

   ```bash
   python main.py
