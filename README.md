# Обработчик анкет

Программа предназначена для обработки анкет студентов и преподавателей. Она проверяет корректность введённых данных, выводит список принятых анкет, формирует статистику и сохраняет результаты обработки.

## Структура проекта

- `main.py` — основной запуск программы.
- `people.py` — классы Person, Student, Teacher и обработка ошибок.
- `registry.py` — класс Registry для загрузки, проверки и хранения анкет.
- `anketa.txt` — исходные данные.

## Формат входных данных

Каждая строка файла `anketa.txt` должна содержать пять полей, разделённых точкой с запятой:

1. Тип анкеты: `s` — студент, `t` — преподаватель.
2. ФИО.
3. Электронная почта.
4. Телефон.
5. Группа или кафедра.

Пример:

```text
s;Иванов Иван Петрович;ivanov@mail.ru;+79211112233;09с34
t;Петров Пётр Сергеевич;petrov@mail.ru;89217654321;Кафедра И9
```

## Запуск

1. Установить Python 3.
2. Поместить исходные анкеты в файл `anketa.txt`.
3. Открыть терминал в папке проекта.
4. Выполнить команду:

```bash
python main.py
```

## Результаты работы

- `ok.txt` — файл с принятыми анкетами.
- `errors.txt` — файл с отклонёнными анкетами и причинами ошибок.

Если файл `anketa.txt` отсутствует, программа выводит соответствующее сообщение.

## Возможности программы

- Проверка правильности ФИО.
- Проверка адреса электронной почты.
- Проверка номера телефона.
- Разделение анкет на студентов и преподавателей.
- Сортировка анкет по ФИО.
- Подсчёт статистики по ролям и группам.
- Сохранение принятых и отклонённых анкет в отдельные файлы.
